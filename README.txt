EFEK TRANSISI KUSTOM

1. Letakkan file efek transisi di folder ini.
2. Buka config.js dan ubah BOTANICAL_TRANSITION_ASSET agar menunjuk ke file tersebut.
   Contoh: 'transitions/efek-daun.webp'
3. Format gambar yang didukung browser: GIF, APNG, WebP, PNG, dan JPG.
   GIF, APNG, atau WebP animasi disarankan untuk efek bergerak.
4. Jika file belum tersedia atau gagal dimuat, efek daun-bunga CSS bawaan akan digunakan.

Untuk menonaktifkan file kustom, ubah nilainya menjadi string kosong: ''
